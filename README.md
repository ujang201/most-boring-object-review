# Most Boring Object Review

One funny, true line reviewing the dullest everyday object I could name — the coaster — for the make.fun bounty [The Most Boring Object, Reviewed in One Line](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3).

## The entry

> The coaster: a cork disc that spends its whole life catching the ring your mug leaves behind, and gets thanked never.

## How it works

`main.ts` composes the review from three parts — the subject, a true observation (a coaster catches the wet ring a mug leaves), and a sting that turns the object's dullness into the punchline — checks it stays on one line within 200 characters, and writes it to `/output/entry.txt`.

## Run

```sh
node main.ts
cat /output/entry.txt
```
